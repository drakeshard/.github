# Support

This file defines the default support path for Drakeshard Studios repositories.

## Bugs

If you found reproducible incorrect behavior in a public project, use that repository's bug report form.

Before filing:

- Search existing issues for duplicates.
- Confirm the issue still occurs on a supported/current version where practical.
- Include clear reproduction steps and environment details.

## Feature requests

Use the repository's feature request form. Describe the problem or player need first, then the proposed solution.

## Questions

For general usage questions, use GitHub Discussions when enabled. If Discussions are not available, check the repository documentation before opening an issue.

## Security

Do **not** use public support channels for security vulnerabilities. Follow [SECURITY.md](SECURITY.md).

## Private and unreleased projects

Public support is not provided for private, internal, or unreleased Drakeshard projects unless explicitly documented by that project.
