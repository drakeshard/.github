# Drakeshard Studios · GitHub Community Health

This repository contains the shared GitHub profile, contribution standards, issue forms, pull request template, security policy, and community defaults used across **Drakeshard Studios** repositories.

## Structure

```text
.
├── profile/
│   └── README.md
├── .github/
│   └── ISSUE_TEMPLATE/
├── CODE_OF_CONDUCT.md
├── CONTRIBUTING.md
├── PULL_REQUEST_TEMPLATE.md
├── SECURITY.md
└── SUPPORT.md
```

Repository-specific files may override these organization defaults when a project needs different requirements.

For the public studio profile, see [profile/README.md](profile/README.md).
